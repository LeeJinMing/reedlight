# Reedlight artwork and tool credits

The entrant directed the reveal. They wanted the three cuts to remain puzzling until one sideways movement brought the kingfisher into focus. The development team designed a bird with a cream eye, a long bill, a raised wing and an orange breast, then split the illustration across three depths.

| Material | Origin |
|---|---|
| Kingfisher, reeds, perch and water | Original geometric illustration for Reedlight. The Python generator draws the shapes with Pillow. It cuts the image into diagonal strips of varying widths and assigns each strip to one of the three sheets. |
| Printed bird | The registered composite of those same sheets. The source PNG retains transparency. |
| Spatial cue cards | Original layout and three cut-paper marks drawn by the project’s Pillow script. Georgia and Segoe UI Bold are rendered from fonts installed on the authoring computer. Only the rendered textures are distributed. |
| Promotional cover | Composed from the original bird, registration marks and typography. Georgia and Georgia Italic were rendered from installed Windows fonts. The image contains rendered lettering. |
| Base project and packages | Snap's SPECS Base Template from Lens Studio 5.25.0, build 26111423. The starting project contains InteractionKit, UIKit, Icons and Motion at 4.0.0. Their package files and upstream notices identify Snap's components. [Lens Studio](https://lensstudio.com/download) |
| Planning and editor tooling | The Devpost Learn plan-lens skill provided the planning format. Snap CLAD and the Lens Studio MCP connected the development tools to the editor. [Devpost Learn skill pack](https://github.com/challengepost/learn-specs) · [Snap CLAD](https://github.com/lens-studio-devs/ls-extensions) |

OpenAI Codex assisted with the concept, geometric illustration, original generators, cue-card layouts, optical model, code, tests, English copy, video captions and editing scripts. Python and Pillow rasterize the original artwork. The demonstration uses a continuous screen recording of the running Lens Studio preview. Its Sunlit Room background comes from Snap’s simulator. Its caption lettering uses installed Windows Georgia and Segoe UI fonts. The film is silent. No stock photos, outside illustrations, font files, voice, music or sound effects are included. The cover is an illustration composed from the original print.
